# FlyStock

[English](README.md) · [Português (BR)](README.pt-BR.md)

Офлайн-трекер предметів для обліку надходження та вибуття обладнання й запасів, із повною історією — без облікового запису, без сервера, без етапу збірки.

## Можливості

- **Облік по кожному предмету** — записуйте кожен предмет із власним описом (наприклад, серійний номер чи інша ознака), а не загальною кількістю.
- **Життєвий цикл «Додати → Видалити → Відновити»** — переміщуйте предмет із поточних запасів до окремого списку видалених із зазначенням часу та причини, і відновлюйте його назад, якщо він був видалений помилково.
- **Історія приміток** — додавайте кілька нотаток із позначкою часу до предмета протягом усього його життєвого циклу (стан, місцезнаходження, джерело тощо).
- **Типи зі згортними, кольоровими групами** — організовуйте предмети за типами; список автоматично групує й розфарбовує їх, а кожну групу можна згорнути або розгорнути.
- **Пакетне додавання** — після додавання одного предмета форма залишається відкритою, очищуючи лише опис, тож можна швидко додати кілька схожих предметів поспіль без повторного введення типу, дати чи нотатки.
- **Пошук** — фільтруйте серед поточних і видалених предметів.
- **Резервні копії та експорт** — експортуйте свій інвентар, включно з нотатками та історією видалень, у простий текстовий файл і імпортуйте його назад (додатково — нічого зі збереженого не перезаписується). Оскільки всі дані зберігаються у браузері, періодичний експорт резервної копії — єдиний спосіб убезпечити ваші дані.
- **Встановлюваний PWA** — встановіть на головний екран і користуйтеся офлайн завдяки service worker.
- **Багатомовність** — доступно англійською, українською та португальською (бразильською).
- **Зберігання лише локально** — усі дані залишаються у `localStorage` вашого браузера; нічого не надсилається на сервер.

## Використання

FlyStock — це один статичний HTML-файл без етапу збірки чи залежностей. Щоб запустити його:

1. Відкрийте `index.html` безпосередньо в браузері, або
2. Запустіть папку через будь-який статичний файловий сервер (наприклад, `npx serve .`) і відкрийте у браузері.
3. За бажанням встановіть його як PWA через запит на встановлення у браузері для офлайн-використання.

## Дані та приватність

Усі дані про інвентар зберігаються локально у вашому браузері через `localStorage`. Нічого не надсилається нікуди. Очищення даних браузера видалить їх, тож регулярно робіть експорт для резервної копії.
